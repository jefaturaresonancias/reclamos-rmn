Política de privacidad

Sistema de Reclamos RMN · Última actualización: 22/08/2026

El Sistema de Reclamos RMN es una herramienta de uso interno del sector de Resonancia Magnética del hospital para gestionar reclamos por informes de estudios y coordinar su entrega a los pacientes. No es una aplicación pública: el acceso está restringido con PIN al personal administrativo y médico del servicio.

Qué datos maneja

Para poder gestionar un reclamo, el sistema guarda:

  • Nombre, apellido y DNI del paciente
  • Estudio realizado y fecha
  • Dirección de email del paciente, cuando se carga para el envío del informe
  • El informe del estudio (PDF) mientras está pendiente de envío

Uso de la API de Gmail

El sistema usa la API de Gmail (permiso gmail.send) exclusivamente para enviar el PDF del informe al email que el paciente dejó al hacer el reclamo, desde la casilla resonancia.santojanni@gmail.com del servicio. Con ese permiso la aplicación solo puede enviar mensajes en nombre de esa casilla — no puede leer, buscar ni modificar el contenido de esa cuenta de Gmail ni de ninguna otra.

El envío lo dispara siempre una persona del personal administrativo, revisando el informe y el destinatario antes de confirmar — no hay envíos automáticos sin intervención humana.

Retención y borrado

El PDF del informe se borra del sistema apenas se confirma el envío. Si un informe queda pendiente de revisión sin enviarse ni rechazarse, se borra automáticamente a los 7 días.

Con quién se comparte

Los datos no se comparten con terceros. El informe se envía únicamente al email del propio paciente que hizo el reclamo, con el fin exclusivo de hacerle llegar el resultado de su estudio.

Contacto
